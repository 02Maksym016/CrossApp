## Структура solution

- `src/Core` — бібліотека зі спільною логікою отримання інформації про середовище.
- `src/Cli` — консольний застосунок для виводу інформації.
- `Cli` має посилання на `Core`.

Залежність проєктів:

`Cli → Core`

## Lab 4 — Доменна модель

У лабораторній роботі створено доменну сутність `Movie`,
яка представляє фільм кінотеатру та контролює правила
створення і зміни свого стану.

### Основні можливості

- Створення фільму через фабричний метод `Create()`.
- Зміна даних через `UpdateDetails()`.
- Архівація та відновлення через `Archive()` і `Restore()`.
- Перетворення сутності в DTO через `ToDto()`.
- Відновлення сутності з DTO через `FromDto()`.

### Інваріанти

1. Ідентифікатор не може бути порожнім.
2. Назва та жанр фільму обов'язкові.
3. Рік має бути в допустимому діапазоні.
4. Тривалість повинна бути більшою за нуль.
5. Архівний фільм не можна змінювати.
6. Не можна повторно архівувати вже архівний фільм. 
7. Не можна відновити фільм, який не перебуває в архіві.

Для некоректних аргументів використовуються
`ArgumentException` і `ArgumentOutOfRangeException`.
Для операцій, заборонених поточним станом об'єкта,
використовується `InvalidOperationException`.

## Лабораторна робота 5 — Сервісний шар

У роботі реалізовано сервісний шар для керування фільмами кінотеатру.

### Реалізовані компоненти

- `ICinemaStore` — інтерфейс для роботи зі сховищем фільмів.
- `InMemoryCinemaStore` — сховище в оперативній пам'яті.
- `FileCinemaStore` — сховище у JSON-файлі.
- `CinemaService` — сервіс для додавання, пошуку, оновлення, архівування, відновлення та видалення фільмів.
- `SampleData` — початкові дані для демонстрації.

### Запуск

Використання сховища в оперативній пам'яті:

```powershell
dotnet run --project src/Cli
```

Використання JSON-файлу:

```powershell
dotnet run --project src/Cli -- --file
```

Дані файлового сховища зберігаються у `data/movies.json`.

### Перевірені операції

- Отримання списку фільмів.
- Додавання нового фільму.
- Пошук фільму за ідентифікатором.
- Оновлення даних фільму.
- Архівування фільму.
- Збереження змін у JSON-файлі.
