
## Лабораторна робота 7 — LINQ-звіти та аналітика фільмів

У лабораторній роботі реалізовано механізм формування звітів та аналізу даних про фільми кінотеатру за допомогою LINQ.

### Реалізовані компоненти

- `MovieReportLine` — модель рядка звіту про фільм.
- `GenreSummary` — модель зведеної інформації за жанрами.
- `ReportService` — сервіс для формування аналітичних звітів.
- `SampleData` — набір початкових даних для перевірки звітів.

### Реалізовані звіти

- `ShortMovies` — пошук фільмів із тривалістю меншою за задане значення.
- `TopByDuration` — вибір найдовших фільмів із сортуванням за тривалістю.
- `ByGenre` — групування фільмів за жанрами та підрахунок кількості.
- `Totals` — обчислення загальної статистики за фільмами.
- `FindAll` — фільтрація фільмів за допомогою LINQ та лямбда-виразів.

### Перевірка роботи

Для демонстрації реалізовано окремі команди:

```powershell
dotnet run --project src/Cli -- report-top
dotnet run --project src/Cli -- report-low
dotnet run --project src/Cli -- report-groups
dotnet run --project src/Cli -- report-sum
dotnet run --project src/Cli -- report-deferred
```

Також доступна демонстрація доменних подій:

```powershell
dotnet run --project src/Cli -- demo-events
```

Перевірено формування звітів, сортування, фільтрацію, групування та підрахунок статистики за даними фільмів.
